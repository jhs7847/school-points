# 바른기록 — 학급 상벌점

학교·학급용 상벌점 웹 앱입니다. 교사는 학생 목록과 모든 상벌점 기록을 보고 점수를 부여할 수 있으며, 학생은 **본인의 기록만** 볼 수 있습니다. 현재는 하나의 기관에서 교사가 모든 학급을 관리하는 구조입니다. 학급별 교사 권한 분리는 제공하지 않습니다.

## 현재 상태

Supabase MCP가 세션에 연결되지 않아 실제 프로젝트, 데이터베이스 및 계정에는 아직 적용되지 않았습니다. 아래 설정이 완료되어야 로그인과 기록이 작동합니다.

## Supabase 설정

1. 새 Supabase 프로젝트의 SQL Editor에서 `supabase.sql`을 실행합니다. 기존 프로젝트에서는 기존 테이블과 `on_auth_user_created` 트리거를 덮어쓸 수 있으므로 그대로 실행하지 마세요.
2. Authentication에서 공개 회원가입을 끄고, 관리자만 교사와 학생 계정을 생성하거나 초대합니다. 계정 생성 시 사용자 메타데이터의 `name`, `class_name`을 입력하면 프로필에 반영됩니다. 기존 계정은 SQL에서 직접 `profiles`를 생성해야 합니다.
3. 새 계정은 기본적으로 학생입니다. 교사 계정을 생성한 뒤 SQL Editor에서 다음을 실행해 교사로 지정하세요. 이메일을 실제 교사 이메일로 바꾸세요.

   ```sql
   update public.profiles set role = 'teacher', name = '선생님 이름'
   where id = (select id from auth.users where email = 'teacher@example.com');
   ```

   학생 이름과 학급도 관리자가 `public.profiles`에서 수정할 수 있습니다.
4. `config.js`에 프로젝트 URL과 **공개용 publishable 또는 anon 키**를 넣습니다. 브라우저에 노출되는 파일이므로 절대 secret/service_role 키를 넣지 마세요.
5. 프로젝트 폴더에서 `npx serve .`을 실행하고 표시된 주소로 접속합니다. 배포 시에도 정적 웹 호스팅을 사용하면 됩니다.

`supabase.sql`은 행 수준 보안(RLS)으로 학생의 타인 기록 조회를 막고, 교사 검증 함수로만 상벌점을 작성하도록 합니다. 민감한 학생 정보를 다루므로 실제 운영 전 학교의 개인정보 처리 기준, 관리자 계정 보호, 접근 통제 및 보관 정책을 검토하세요. 기록 수정·삭제, 학급별 교사 분리, 학부모 접근, 알림 기능은 포함되지 않습니다.
